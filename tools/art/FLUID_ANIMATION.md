# Run and dive frame expansion

Built-in imagegen authored eighteen new poses per character from the approved selection sprite: twelve running drawings and six dive phases. Sources are `<id>_sources/fluid-v1.png`. `inspect-fluid.ps1` extracts alpha-connected sprites; `pack_fluid.gd` appends them to each existing atlas without replacing other actions. Runtime atlases are `assets/art/characters/<id>.webp` with JSON timing and anchors. Run holds total 32 simulation ticks. Dive launch/reach takes nine ticks; landing/get-up takes seven ticks, matching the movement and recovery phases. Backward running still reverses phase.

The flying-disc presentation is lifted from 30 to 85 court-height units, putting the projected catch region at the upper body. Floor collision radius and rollback rules remain unchanged. Show Catch Zones projects the same collision radius at flying-disc height, while lobs retain their floor target. Held discs now follow sprite stretch and rotation.
