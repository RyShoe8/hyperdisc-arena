## Revised masters (v2)

The v1 designs were rejected as too similar to the existing roster, especially Vanessa. These replacements change costume construction, hairstyle, build and posture while retaining arcade pixel rendering. Built-in imagegen used each v1 only as a rendering reference. Current masters: `keno_sources/design-v2.png`, `steve_sources/design-v2.png`, `vanessa_sources/design-v2.png`. All three revised directions were approved. v0.2.3 integrates their portraits, selection art and 16-frame playable atlases. See THIRD_ROSTER_PROMPTS.md for animation prompts. This first pass uses shared throw poses for lob/slap/special, catch for block, and idle for charge/win/lose; dedicated poses and stride consistency remain refinement work.
