## Animation pass

Built-in imagegen was used for all source artwork. `run-v1.png` contains six run poses; `actions-v1.png` contains throw/catch sequences plus dash/jump/landing poses. Tiffany's current sheets use the corrected red one-piece. The previous sportswear sheets are retained as studies.

Packing: `inspect-roster.ps1` isolates connected sprites into component metadata; `build_roster_pixel.gd` crops/aligns them into 512-pixel atlas cells using nearest sampling. Anchors are first-pass estimates. Idle uses the master pose; lob/slap/special reuse throw, block reuses catch, knock reuses dash, and charge/win/lose reuse idle. Further motion refinement remains.
